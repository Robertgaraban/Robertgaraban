## Cómo trabajo

- **Primero la operación.** Inventario procesos, herramientas, responsables, frecuencia y puntos de fallo antes de proponer tecnología.
- **La herramienta adecuada para cada parte.** Separo lo que resuelve el software convencional, lo que resuelve una automatización y lo que necesita IA generativa.
- **Criterios de aceptación antes de construir.** Cada pieza tiene una definición de «hecho» que se puede comprobar.
- **IA con límites.** Diseño permisos, trazabilidad, datos que nunca salen hacia el modelo, topes de coste, límites de actuación y métricas de resultado.
- **Puesta en marcha y adopción.** Organizo cargas de datos por lotes controlados, copias previas, comprobaciones de integridad, documentación, pruebas por responsabilidad y circuitos de incidencias.
